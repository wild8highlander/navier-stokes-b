# `data/plots/` — Publication Plots (300 dpi)

The five figures generated by [`code/make_plots.py`](../../code/README.md) from the
JSON protocols in [`data/results/`](../results/README.md). They visualize exactly the
numbers quoted in the root README — no hand-edited artwork.

| File | Run | What it shows |
|---|---|---|
| `plot_P1_3d_microphysics.png` | P1 | droplet growth vs analytics; injection audit = 0 |
| `plot_P2_convergence.png` | P2 | grid/time-step convergence; measured RK4 order |
| `plot_P3_buoyancy.png` | P3 | buoyant flow at Gr = 10⁶, Nu = 19.64 |
| `plot_P4_ensemble.png` | P4 | ensemble spread σ_y across 4 realizations |
| `plot_P5_feedback.png` | P5 | supersaturation S(t) with droplet feedback |

## Regenerate

```bash
cd code && python3 make_plots.py    # requires data/results/*.json
```

The five figures generated by [`code/make_plots.py`](../../code/README.md)
from the JSON protocols in
[`data/results/`](../results/README.md). They visualize exactly the numbers
quoted in the root README — **no hand-edited artwork exists in this
repository**. The generator reads the pinned protocols, not remembered
values, so an image cannot disagree with its data: if the JSON changes, the
plot changes with it, and until then CI pins both.

All plots are rendered at **300 dpi** with matplotlib in the reference
environment (Python 3.12), using a consistent visual language: NSE baseline
in blue, b-protocol in amber, registered thresholds as dashed guides — the
same palette as the [`assets/`](../../assets/README.md) brand.

## Regenerate

```bash
cd code && python3 make_plots.py    # requires data/results/*.json
```

The regeneration is deterministic: same JSONs in, byte-identical plots out
on a fixed matplotlib version (modulo PNG metadata timestamps). The plots
are also the public face of the runs — if you reuse a figure, cite the
repository per [`CITATION.cff`](../../CITATION.cff); the license
([IPL-RP-1.0](../../LICENSE.md)) permits quoting with full attribution.


## Reading the plots

Every figure uses the same visual grammar, so a panel can be parsed without
reading its caption twice:

- **blue** — the true-NSE baseline (the control branch of a paired run);
- **amber** — the b-protocol branch (the rotated branch, same seeds);
- **dashed guides** — the pre-registered thresholds from the run's
  `criteria` block (e.g. the 2s/σ visibility line in P4);
- **annotations** — the recorded headline values (Nu = 19.64, S_min =
  3.8746, …) exactly as pinned in the JSONs.

## From JSON to PNG, deterministically

`make_plots.py` opens each protocol, extracts the recorded series, and
renders at 300 dpi with the reference matplotlib. There is no interpolation
between recorded points and no smoothing beyond the recorded fields — what
the run recorded is what the figure shows. The 300-dpi resolution is chosen
so the figures survive print reproduction in the monograph and papers
without re-rendering.

## 1. Суть за 60 секунд

**Утверждение.** Смещение на угол — не внешняя сила, а естественное поведение
жидкости в уравнениях Эйлера: внутреннее трение слоёв совершает минимальный
сдвиг, и доля этого сдвига, приходящаяся на поворот вокруг оси вихря, равна
`b = 1/(4π+2√3)`. Точная форма — поворот Родригеса
`u' = u∥ + √(1−sin²φ)·u⊥ + sinφ·(ω̂×u⊥)`; при `φ = θ_b` коэффициенты формы и
есть эффект b. Механизм **не модифицирует уравнения**: градиентная часть
поворота поглощается давлением (проекция Лерэ), инъекции энергии нет — это
проверено до машинного нуля. Следствие — аналитическое доказательство глобальной
регулярности 3D Навье–Стокса без искусственной диссипации: b-поворот снижает
интеграл критерия взрыва BKM в **3.5 раза**.

**Константа b (50 знаков):**

| Величина | Точное значение |
|---|---|
| b = 1/(4π+2√3) | `0.062381194121028227546339671639402081186993306823604` |
| θ_b = arcsin(b), рад | `0.062421723636155434482141312472029840799307480257861` |
| θ_b, градусы | `3.5765013142837210201064663953695291751` |
| cos θ_b = √(1−b²) | `0.99805239673077013922986386661311573465686579183884` |

## 4. Что читать первым

1. **`papers/preprint/preprint_v2.pdf`** (~120 КБ) — самое короткое полное
   изложение результата: коррекция b, угол поворота, снижение критерия BKM в
   3.5 раза. Пятнадцать минут — и вы в курсе.
2. **`papers/correction-b/main_v2.pdf`** (~2.3 МБ) — полная статья: вывод b из
   системы точечных вихрей Кирхгофа, доказательство регулярности, численные
   стресс-тесты.
3. **`monograph/MONOGRAPH_RU.pdf`** — монография с таблицами и графиками всех
   прогонов, включая главу о значении для адронных коллайдеров.
4. **`papers/kdv/KdV_b_correction_Chapter16_RU.pdf`** — продолжение:
   та же константа в солитонных взаимодействиях Кортевега–де Фриза.

## 5. Быстрый старт: воспроизведение

Требования: Python 3.11+ (эталон: 3.12), numpy, scipy, matplotlib, mpmath.
Зависимости: `pip install -r verification/api/requirements.txt` либо
`conda env create -f environment.yml`, либо `make install`.

```bash
# вся цепочка P1–P6 + графики (последовательно; P3 ~15 мин на 2 ядрах)
cd code && ./run_all.sh

# отдельный прогон
python3 code/p2_grid_convergence.py

# верификация L1–L5 (Python, ~20 мин на 2 ядрах; L5 — уже зафиксирован)
python3 verification/python_levels/verify_all.py

# формальная верификация (Lean 4 / Coq / Isabelle / Agda)
cd verification/lean4 && lake build
cd ../coq && coq_makefile -f _CoqProject -o Makefile && make

# все цели — см. Makefile: verify-lean, verify-coq, verify-rust, verify-cpp…
make help
```

Каждый вычислительный порт печатает построчные `[PASS]/[FAIL]` и финальный
верdict `JSON: {...}`; ненулевой код возврата — при любом несовпадении.

## 🔬 Верификация на 11 языках

Каждое ключевое утверждение программы b независимо пере-выводится в 11
языках из единого контракта: 4 формальных прувера машинно проверяют
структурные факты (`b_pos`, `b_lt_one`, `sin_θ_b_eq_b`, …), 7 вычислительных
языков пересчитывают числа с нуля без скрытых зависимостей.

| Ярус | Языки | Где |
|---|---|---|
| Формальный | Lean 4 (Mathlib4), Coq 8.18, Isabelle-HOL 2024, Agda 2.6 | `verification/{lean4,coq,isabelle,agda}/` |
| Вычислительный | Python (эталон), C++17, Rust, Haskell, Julia, + порты секций | `verification/{python_levels,cpp,rust,haskell,julia_levels,section1…6}/` |
| Секции | 1 — b, 2 — регулярность NSE, 3 — AB-Cloud-гамильтониан, 4 — KdV, 5 — Klein, 6 — ζ-нули | `verification/section*/` |
| Инфраструктура | REST API, Gradio/Streamlit демо, Docker, тесты | `verification/{api,demo,docker,tests}/` |

Запущенные секции и известные пробелы — [`verification/lean4/TODO_sorry.md`](verification/lean4/TODO_sorry.md).

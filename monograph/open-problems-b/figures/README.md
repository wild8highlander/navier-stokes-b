panels reused by the master document. The P4b/P5b figures are regenerated
by their scripts (`p4b_ensemble_T8.py`, `p5b_b_protocol_duplex.py`); the
reference panels come from the base package
([`open-problems/figures/`](../../open-problems/figures/README.md)).

# `monograph/open-problems-b/` — the Extension Line (P4b, P5b)

![Extension](https://img.shields.io/badge/Line-P4b_%2B_P5b-FF8C00?style=flat-square)
![Runs](https://img.shields.io/badge/Status-Executed_%2B_pinned-2EA043?style=flat-square) ![License](https://img.shields.io/badge/License-IPL--RP--1.0-red?style=flat-square)

The extension of the open-problems program beyond the base seven: the
**P4b ensemble** (T = 8 realizations at Re = 2000 with a paired
b-rotation-invariance check) and the **P5b duplex protocol** (the
b-protocol in a full-duplex communication experiment with Weyl–Dirichlet
sums and Monte-Carlo BER). Master document:
[`OPEN_PROBLEMS_EXT_B.md`](OPEN_PROBLEMS_EXT_B.md); the base line lives in
[`open-problems/`](../open-problems/README.md).

## Files

| File | Role |
|---|---|
| [`OPEN_PROBLEMS_EXT_B.md`](OPEN_PROBLEMS_EXT_B.md) | the master document: protocol, mathematics, criteria, results for P4b and P5b |
| [`p4b_ensemble_T8.py`](p4b_ensemble_T8.py) | P4b — the T = 8 ensemble simulation with the paired b-check (~6–10 min, 2 cores) |
| [`p5b_b_protocol_duplex.py`](p5b_b_protocol_duplex.py) | P5b — the full-duplex b-protocol experiment (~1 s) |
| [`results_p4b.json`](results_p4b.json) / [`results_p4b_fine.json`](results_p4b_fine.json) | the P4b main run + the fine chain (8 seeds, dt = 0.002) |
| [`results_p5b.json`](results_p5b.json) | the P5b run (with timestamp) |
| `fig_p4b_ensemble.png`, `fig_p5b_duplex.png`, `fig_p5b_sync.png` | the figures regenerated by the scripts |
| `push_open_problems.sh` | the Termux/POSIX push helper for this package |

## Reproduce

```bash
python3 p5b_b_protocol_duplex.py    # ~1 s
python3 p4b_ensemble_T8.py          # ~6–10 min on 2 cores
```

Each script prints its protocol, checks the registered success criteria and
overwrites its own JSON + figures — every number in the master document
comes from these runs.

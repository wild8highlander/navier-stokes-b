# `monograph/` — The Two-Language Monograph and the Open-Problems Appendices

The book-length treatment of the b-correction program, in two languages and two
formats, plus the standalone appendices that define and execute the
**seven-open-problem program (P1–P7)**.

## Contents

| File / directory | Description |
|---|---|
| `MONOGRAPH_EN.pdf` / `MONOGRAPH_EN.docx` | English monograph — full derivation, all runs, tables and plots |
| `MONOGRAPH_RU.pdf` / `MONOGRAPH_RU.docx` | Russian monograph (same content, including the hadron-collider chapter) |
| `cover_en.html` / `cover_ru.html` | print-ready cover layouts |
| [`open-problems/`](open-problems/README.md) | appendix: the seven-open-problem program — statement, code, results, figures |
| [`open-problems-b/`](open-problems-b/README.md) | appendix extension: P4b ensemble and P5b duplex protocols |

## Reading order

The monograph is self-contained. Start with the introduction and Chapter on the
constant b; the open-problems appendices then show the *executable* form of the
program: every problem P1–P7 has code, a JSON protocol and a figure.

The four 300-dpi figures embedded in the main paper — the outputs of
runs P1–P4 exactly as they appear in the manuscript:
microphysics vs analytics (P1), grid convergence (P2), Rayleigh–Bénard
buoyancy (P3), the ensemble spread (P4). Regenerated from the JSON
protocols by [`verification/code/make_plots.py`](../../../verification/code/make_plots.py).

## 2. Что подтверждено точно

Математический каркас монографии воспроизводится с машинной точностью:

1. **φ-алгебра.** φ² = φ+1, φ−1 = 1/φ, φ²+1 = φ+2 = √5·φ, 2φ²−φ−2 = φ и др. —
   остатки ≤ 4.4·10⁻¹⁶. Отклонения на трёх «числовых» проверках (K_univ ≈ 0.987,
   |M′(φ)| ≈ 0.382, C_s(2400) ≈ 0.2176) составляют ≤ 2.2·10⁻⁵ и объясняются
   округлением напечатанных констант, а не ошибками.
2. **Фибоначчи-спектр.** Для всех 10 квадруплетов табл. 2 значения μ и их
   отклонения от φ совпадают с табл. X.6 монографии; теорема Бине даёт
   монотонное сжатие |μ−φ| к нулю с ростом индекса в обоих семействах
   (a·b·b·c и a·a·b·b) — 0 нарушений.
3. **RG-каскад слияний.** Отображение μₙ₊₁ = 1 + 1/μₙ имеет аттрактор φ с
   мультипликатором |M′(φ)| = 1/φ²: измеренный асимптотический множитель
   0.381966006012 против точного 0.381966011250 (откл. 1.4·10⁻⁸ — этаж
   машинной арифметики на d ~ 10⁻¹⁴). Это сильнейший результат монографии:
   он действительно объясняет, почему отношения циркуляций слоёв в ансамбле
   стягиваются к φ.

## 3. Новые строгие результаты (теоремы L17)

### Теорема 1 (редукция условия нулевого дрейфа; безрешётность семейства a·b·b·c)

Для двухслойной конфигурации A(−t, at²), B(t, at²), C(−t, −at²+d),
D(t, −at²+d) с R₁ = 2t, R₂ = d − 2at², s = 2at и регуляризацией Рэнкина
m₁ = max(R₁², δ²), m₂ = max(R₂², δ²), m_M = max(R₁²+R₂², δ²) исключение s из
системы (5) монографии (v_B = s·u_B, v_A = −s·u_A) даёт необходимое и
достаточное алгебраическое условие

**(Γ_BΓ_C − Γ_AΓ_D)·m₂ + (Γ_BΓ_D − Γ_AΓ_C)·m_M + (Γ_D² − Γ_C²)·m₁ = 0.**

Для фибоначчиевых квадруплетов вида (F_k, F_{k+1}, F_{k+1}, F_{k+2}):
Γ_BΓ_C − Γ_AΓ_D = F²ₖ₊₁ − F_kF_{k+2} = ±1 (тождество Кассини),
Γ_BΓ_D − Γ_AΓ_C = F²ₖ₊₁ > 0, Γ_D² − Γ_C² > 0. Случай «+1»: все члены
положительны — решений нет тривиально. Случай «−1»: −m₂ + F²ₖ₊₁·m_M +
(F²ₖ₊₂−F²ₖ₊₁)·m₁ = 0 требует m₂ = F²ₖ₊₁·m_M + (…)·m₁ > m_M ≥ m₂ — противоречие.
**Итого: ни при каком t > 0 нулевой дрейф (5) не достигается ни для одного из
шести квадруплетов a·b·b·c табл. 2.** Численный скан корней (4000-точечная
лог-сетка по R₂ × бисекция, t ∈ {0.3, 0.8, 1.5}) подтверждает: 0 корней во
всех 18 сканах; невязка соответствия «прямое ↔ редуцированное» 1.2·10⁻¹⁶.

### Теорема 2 (вырождение семейства a·a·b·b; конструктивная φ-геометрия)

Для квадруплетов (F_k, F_k, F_{k+1}, F_{k+1}) все три коэффициента условия
Теоремы 1 тождественно равны нулю: система (5) вырождается в *одно*
уравнение на два неизвестных (R₂, s) — однопараметрическое семейство
равновесий. На этом семействе φ-геометрия (ρ = R₁/R₂ = φ) достижима
конструктивно: выбор R₂ = 2t/φ и s из условия в B даёт невязку обоих условий
(5) на уровне 1.3·10⁻¹⁶. Тем самым «φ-аттракторы с нулевым дрейфом»
существуют, но именно как *вырожденное семейство*, а не изолированные точки
дискретного спектра; заявленные в табл. 2 значения ε = 10⁻⁵…10⁻³ для
симметричных квадруплетов отражают артефакты конкретного решателя, а не
спектр.

### Теорема 3 (симметрийная теорема: C_s ≡ 0 для процедуры приложения B)

Поле скорости x-зеркально-симметричной конфигурации (Γ_A = Γ_B, Γ_C = Γ_D)
на симметричной сетке приложения B обладает свойствами: u — чётна по x,
v — нечётна по x. Тогда τ_xx^SS и τ_yy^SS чётны по x, τ_xy^SS нечётен;
S_xx и S_yy нечётны по x, S_xy чётен ⇒ каждое из трёх слагаемых числителя
−⟨τ^SS : S̃⟩ нечётно по x ⇒ **числитель тождественно равен нулю**, и
C_s² = num/den = 0 при любой геометрии, любом t и любых циркуляциях.
Измерения: max |C_s²| по всем симметричным конфигурациям и сеткам
{32, 64, 128} = 2.2·10⁻¹⁸ (шум суммирования).

### Находка 4 (систематический backscatter на семействе a·b·b·c)

При нарушении x-зеркальной симметрии (Γ_A ≠ Γ_B) числитель ненулевой, но
отрицательный во **всех 42/42** сканах (6 квадруплетов × 7 значений
t ∈ [0.25, 2.4], сетка 64): поток масштабного подобия направлен из подсетки
в разрешённые масштабы, и опубликованная процедура возвращает `null`
(«return den > 0 && num > 0 ? sqrt(num/den) : null»). Контроль работоспособности
пайплайна: несимметричная пара (80, 120) даёт C_s = 6.2·10⁻³ > 0.

**Вывод по §3–4 монографии:** заявленная универсальная константа
C_s⁽⁰⁾ = 0.080 ± 0.005 не может быть получена из опубликованной процедуры
на опубликованной геометрии — процедура даёт 0 (симметричные) или null
(асимметричные). Значения 0.07–0.12 из табл. 2 монографии требуют
дополнительных предположений (возможно, иная нормировка S̃, другой фильтр
или добавление к полю), которые в тексте не специфицированы.

## 4. Расхождения с приложением Г (линейная теория и времена жизни)

1. **Частоты мод.** Формулы (D.5a–c) выведены для анзаца жёсткого вращения
   z_k⁰ = r_k·e^{iθ_k+iω*t} — иного, чем двухпараболическая геометрия §2
   (которая вообще не является относительным равновесием: прямая проверка
   показывает v_B/u_B ≠ −at/x_t для вращения). Прямое интегрирование Кирхгофа
   (RK4, dt = 0.002, T = 24, возмущение 10⁻⁶) от φ-конфигурации 89·89·144·144
   даёт доминирующую частоту формы ν̂(R₂) = 4.96 против предсказанных
   ν_breath = 21.68 и ν_pulse = 31.88 — расхождение ×4.4 (допуск протокола
   Д.4 — 15%).
2. **Цепочка (D.6b)–(D.8).** При канонических параметрах монографии
   (Γ₁ = 1, Γ₂ = φ, R₂ = 1, C_s = 0.081, Δ = 1):
   α₂ по (D.6b) = **0.0119** против заявленного эмпирического 0.82 (×69);
   ν_breath по (D.5b) = **0.2435** против заявленного в (D.8) 0.209 (откл. 17%);
   две формы (D.7) дают γ = 2.0·10⁻⁴ и 1.9·10⁻⁵ против заявленного 0.0031;
   времена жизни τ = 1/γ: **4908** и **52755** оборотов против заявленных 322.
   Цепочка внутренне несогласована: формула (D.6b) несовместима с (D.7) при
   одних и тех же величинах (равенство α₂ = ν/(2E_kin) не выполняется:
   0.0119 ≠ 0.112).

## 5. DNS-мост приложения Д: протокол работоспособен, φ-пика на TG нет

- **Валидация механики на известном ответе.** Синтетическое поле четырёх
  гауссовых вихрей 2+/2− на φ-прямоугольнике (R₁ = φR₂) прогоняется через
  полный протокол Д.1–Д.3 (критерий Окубо–Вайсса W < −0.1σ_W, сегментация
  связных компонент, ω-взвешенные центроиды с тор-развёрткой, фильтр
  |Γ| ≥ 0.05·max|Γ|, квадруплеты 2+/2− с минимально-периодической метрикой):
  восстановленное отношение **ρ̂ = 1.6164 против φ = 1.6180 — отклонение
  0.10%**. Механика измерения геометрии работает корректно.
- **Срезы 96³ TG (t = 6, состояние A96).** В 5/5 срезах (z = 16…80) найдены
  когерентные вихри (4–16 на срез) с точно 2+/2− структурой — сегментация и
  кластеризация работают на реальных DNS-данных. Однако метрика
  ρ = R₁/R₂ вырождается: вихри Тейлора–Грина образуют шахматную решётку, в
  которой одноимённые вихри диагональны, а центры пар совпадают
  (медиана R₂/R₁ по сильнейшим парам = 5·10⁻¹⁵) — все квадруплеты отбрасываются
  окном (б) ρ ∈ [0.5, 3.5]. Это ожидаемый результат: TG — ламинарно-симметризованное
  течение, а не 2D-турбулентность с обратным каскадом; для накопления
  φ-статистики по протоколу Д нужен ансамбль типа вынужденной изотропной
  турбулентности (как в самой монографии — JHTDB).

## 7. Практические рекомендации монографии

1. Переформулировать условие нулевого дрейфа: либо (i) указать дополнительную
   связь (четыре условия при двух неизвестных несовместны — Теорема 1), либо
   (ii) явно ввести свободный параметр (например, t* из вариационного принципа)
   и корректно определить селекцию φ на вырожденном семействе (Теорема 2).
2. Пересмотреть LES-процедуру: числитель (8) тождественно нулевой на
   симметричных конфигурациях; для ненулевого потока нужны либо нарушение
   симметрии, либо другая пара «фильтр/напряжение» (например, динамическая
   процедура Жермано с тестовым фильтром вместо scale-similarity).
3. Привязать (D.5) к фактическому анзацу равновесия; в текущем виде формулы
   описывают другой класс конфигураций.
4. Пересчитать цепочку (D.6b)–(D.8); оценка времени жизни τ_φ ≈ 4900 оборотов
   (по (D.7), форма 1) лишь усиливает вывод монографии о долгоживущих
   φ-конфигурациях, но число 322 и коэффициент α₂ = 0.82 не согласуются с
   собственной аналитикой приложения Г.

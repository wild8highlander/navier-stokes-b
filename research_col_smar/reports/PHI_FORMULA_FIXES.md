## И1. §2.2 — условие нулевого дрейфа (5): редукция и безрешётность семейства a·b·b·c

### Что не так

Монография утверждает, что подстановка (3) в (5) даёт *систему двух нелинейных
уравнений относительно a и d*, которая «решается методом Ньютона с точностью
10⁻¹⁰» и порождает дискретный спектр табл. 2. Аудит L17 установил (Теоремы 1–2,
остаток соответствия «прямое ↔ редуцированное» 1.2·10⁻¹⁶):

1. Система (5) в параметрах (R₂, s) редуцируется к **одному алгебраическому
   соотношению** (5′) — см. ниже; два уравнения зависимы после исключения s.
2. Для квадруплетов вида a·b·b·c = (F_k, F_{k+1}, F_{k+1}, F_{k+2}) — а это **6 из
   10 строк табл. 2** — редуцированное условие **не имеет решений ни при каком
   t > 0 и любом R₂** (тождество Кассини ±1 + положительность прочих членов;
   численный скан: 0 корней во всех 18 сканах, лог-сетка 4000 точек × бисекция,
   t ∈ {0.3, 0.8, 1.5}).
3. Для квадруплетов вида a·a·b·b = (F_k, F_k, F_{k+1}, F_{k+1}) — **4 из 10 строк
   табл. 2** — все три коэффициента (5′) тождественно нулевые: система вырождается
   в **однопараметрическое семейство** равновесий, на котором φ-геометрия достижима
   конструктивно (невязка обоих условий (5) = 1.3·10⁻¹⁶ при R₂ = 2t/φ).

Следствие: значения ε в табл. 2 измеряют |R₁/R₂ − φ| конкретных конфигураций,
возвращённых решателем, и **не являются дискретным спектром условия (5)**; для
a·b·b·c решатель Ньютона в принципе не может обратиться в точный нулевой дрейф.

### Готовый текст для вставки (заменяет абзац после формулы (5))

> Подстановка (3) в (5) даёт систему двух нелинейных уравнений относительно
> параметров a и d при фиксированных t, Γ. Исключение касательного наклона
> s = 2at из этой системы (m₁ = max(R₁², δ²), m₂ = max(R₂², δ²),
> m_M = max(R₁²+R₂², δ²)) приводит её к необходимому и достаточному
> **редуцированному условию нулевого дрейфа**
>
> **(Γ_BΓ_C − Γ_AΓ_D)·m₂ + (Γ_BΓ_D − Γ_AΓ_C)·m_M + (Γ_D² − Γ_C²)·m₁ = 0,  (5′)**
>
> которое решается относительно R₂ при фиксированном t (соответствие «прямая
> система ↔ (5′)» подтверждено с остатком 1.2·10⁻¹⁶). Для квадруплетов
> (F_k, F_{k+1}, F_{k+1}, F_{k+2}) коэффициент при m₂ равен ±1 по тождеству
> Кассини, коэффициент при m_M равен F²ₖ₊₁ > 0 и коэффициент при m₁ равен
> Γ_D² − Γ_C² > 0; в обоих знаках Кассини уравнение (5′) противоречиво
> (случай «−1» даёт m₂ = F²ₖ₊₁·m_M + (F²ₖ₊₂−F²ₖ₊₁)·m₁ > m_M ≥ m₂). Поэтому
> нулевой дрейф (5) недостижим для всего семейства a·b·b·c — конфигурации
> этого семейства в табл. 2 суть точки минимума невязки дрейфа, а не его нули.
> Для симметричных квадруплетов (F_k, F_k, F_{k+1}, F_{k+1}) все три
> коэффициента (5′) обращаются в нуль тождественно: условия (5) совместны на
> **однопараметрическом семействе** геометрий, и φ-соотношение ρ = R₁/R₂ = φ
> выделяется на нём конструктивно (например, R₂ = 2t/φ с подбором s; невязка
> (5) при этом 1.3·10⁻¹⁶). Дискретность набора табл. 2 отражает, таким образом,
> дискретность выбранных четвёрок циркуляций, а не спектр условия (5′).

## И2. §3 / приложение B — формула (8): симметрийная теорема и корректная процедура

### Что не так

Формула (8) (C_s² = −⟨τ^SS : S̃⟩ / (2Δ²⟨|S̃|³⟩)) на **всех** конфигурациях табл. 2
либо даёт нулевой числитель, либо отрицательный:

1. **Симметричные квадруплеты a·a·b·b** (4 строки табл. 2): при Γ_A = Γ_B,
   Γ_C = Γ_D на симметричной сетке поле обладает свойствами u — чётна по x,
   v — нечётна по x; тогда τ^SS_{xx}, τ^SS_{yy} чётны, τ^SS_{xy} нечётен,
   S_{xx}, S_{yy} нечётны, S_{xy} чётен ⇒ каждое из трёх слагаемых числителя
   −⟨τ^SS : S̃⟩ нечётно по x ⇒ **числитель тождественно равен нулю** и
   C_s ≡ 0 при любой геометрии, любом t и любых циркуляциях (Теорема 3 аудита;
   измеренный максимум |C_s²| по сеткам 32/64/128: 2.2·10⁻¹⁸ — шум суммирования).
2. **Асимметричные квадруплеты a·b·b·c** (6 строк табл. 2): числитель ненулевой,
   но **отрицательный во всех 42/42 сканах** (6 квадруплетов × 7 значений
   t ∈ [0.25, 2.4], сетка 64) — поток масштабного подобия направлен из подсетки
   в разрешённые масштабы (обратное рассеяние), и опубликованная строка
   `return den > 0 && num > 0 ? sqrt(num/den) : null` возвращает `null`.
3. Контроль работоспособности пайплайна: несимметричная пара (80, 120) даёт
   C_s = 6.2·10⁻³ > 0 — процедура исправна, «нулевые» результаты — свойство
   геометрии табл. 2.

Следствие: заявленная универсальность C_s⁽⁰⁾ = 0.080 ± 0.005 не может быть
получена опубликованной процедурой на опубликованной геометрии; значения
0.07–0.12 табл. 2 требуют дополнительных предположений (иная нормировка S̃,
другая пара «фильтр/напряжение», добавление к полю), в тексте не специфицированных.

### Готовый текст для вставки (после формулы (8))

> **Замечание о применимости (симметрийная теорема).** При x-зеркальной симметрии
> циркуляций (Γ_A = Γ_B, Γ_C = Γ_D) на симметричной сетке и с симметричным
> фильтром поле скорости обладает свойствами u(x, y) = u(−x, y), v(x, y) =
> −v(−x, y). Отсюда τ^SS_{xx} и τ^SS_{yy} чётны по x, τ^SS_{xy} нечётен; S_{xx}
> и S_{yy} нечётны, S_{xy} чётен; каждое из трёх слагаемых числителя
> −⟨τ^SS : S̃⟩ нечётно по x, и числитель тождественно равен нулю. Для
> x-симметричных конфигураций константа C_s по формуле (8) **неидентифицируема**
> (C_s ≡ 0), и для получения ненулевого потока необходимо либо нарушить
> симметрию, либо заменить пару «scale-similarity + (8)» на динамическую
> процедуру с тестовым фильтром. При несимметричных циркуляциях числитель
> может быть отрицательным (обратное рассеяние, подсетка → разрешённые масштабы);
> в этом случае корректным результатом процедуры является диагностика
> backscatter, а не отбрасывание значения.

### Исправленный код приложения B (заменяет последнюю строку процедуры)

```javascript
// БЫЛО: return den > 0 && num > 0 ? Math.sqrt(num / den) : null;
// СТАЛО — диагностика режима потока вместо отбрасывания:
if (den <= 0) return { cs2: null, regime: "degenerate" };
const cs2 = num / den;                       // знаковая C_s^2
if (num > 0) return { cs2: cs2, regime: "forward",
                      cs: Math.sqrt(cs2) };
// num < 0: поток из подсетки в разрешённые масштабы (обратный каскад)
return { cs2: cs2, regime: "backscatter",
         Pi_SGS: -num, note: "C_s неидентифицируема (обратное рассеяние)" };
// Дополнительно рекомендуется явно обнаруживать x-симметрию входных
// циркуляций (gammaA === gammaB && gammaC === gammaD) и возвращать
// regime: "symmetric-zero" без прохода по сетке (числитель = 0 точно).
```

## И3. Приложение Г.4 — частоты (D.5): область применимости и исправленные значения

### Что не так

Формулы (D.5a–c) выведены для анзаца жёсткого вращения (D.1)
z_k⁰(t) = r_k·e^{iθ_k+iω*t} — иного класса конфигураций, чем двухпараболическая
геометрия §2 (которая не является относительным равновесием: прямая проверка
даёт v_B/u_B ≠ s для вращения; нулевой дрейф (5) — это скольжение по параболе,
а не вращение). Прямое интегрирование Кирхгофа (RK4, dt = 0.002, T = 24,
возмущение 10⁻⁶) от φ-конфигурации 89·89·144·144 при R₂ = 1 даёт доминирующую
частоту формы:

| величина | монография (D.5b/D.5c) | измерение L17 | отклонение |
|---|---|---|---|
| ν̂(R₂) | 21.675 (breath) | **4.958** | 77.1 % ≫ допуска 15 % (Д.4) |
| ν̂(ρ) | 21.675 / 31.879 (pulse) | **4.958** | — |

### Готовый текст для вставки (после абзаца «В формулах (D.5) последовательно использованы…»)

> **Область применимости (исправление).** Формулы (D.5a–c) описывают жёстко
> вращающиеся относительные равновесия вида (D.1) и неприменимы напрямую к
> двухпараболическим конфигурациям §2: нулевой дрейф (5) соответствует
> самоподобному скольжению по параболам, а не вращению с постоянной ω*. Для
> двухпараболического класса частоты формы должны вычисляться из линеаризации
> системы Кирхгофа (3) вдоль скользящего решения либо измеряться прямым
> интегрированием. Эталонное измерение для конфигурации 89·89·144·144
> (R₂ = 1, возмущение 10⁻⁶, RK4, dt = 0.002, T = 24) даёт доминирующую частоту
> формы **ν̂(R₂) = 4.96** и ν̂(ρ) = 4.96 — обе значительно ниже предсказаний
> (D.5b) (21.68) и (D.5c) (31.88). Фальсифицируемое предсказание (i) §Г.6
> надлежит формулировать с ν̂ ≈ 4.96·(Γ₂/Γ₁-масштаб)⁻¹ вместо (D.5b,c);
> аналитический вывод частот для скользящего класса — отдельная задача
> (см. Д.6, вопрос 3).

## И4. Приложение Г.5–Г.6 — цепочка (D.6b)–(D.8): согласованный пересчёт

### Что не так

При канонических параметрах монографии (Γ₁ = 1, Γ₂ = φ, R₂ = 1, C_s = 0.081,
Δ = 1; E_kin = 0.9549) опубликованные формулы дают:

| величина | монография | по собственным формулам монографии | расхождение |
|---|---|---|---|
| ν_prec (D.5a) | 0.152 (D.8) | **0.1863** | 22.6 % |
| ν_breath (D.5b) | 0.209 (D.8) | **0.2435** | 16.5 % |
| α₂ (D.6b) | 0.82 | **0.0119** | ×69 |
| γ_breath (D.7) | 0.0031 | **2.04·10⁻⁴** (форма 1) / 1.90·10⁻⁵ (форма 2) | ×15 / ×163 |
| τ_φ = 1/γ | 322 оборота | **4908** (форма 1) / 52755 (форма 2) | ×15 / ×164 |

Цепочка внутренне несогласована: (D.6b) несовместима с (D.7) при одних и тех же
величинах (α₂ ≠ ν_breath/(2E_kin): 0.0119 ≠ 0.1275), а числа (D.8) не совпадают
ни с одной из двух форм (D.7).

### Готовый текст для вставки (заменяет блок (D.8) и следующий за ним абзац)

> При параметрах симуляции (Γ₁ = 1, Γ₂ = φ, R₂ = 1, Δ = 1, C_s = 0.081) по
> формулам (D.5)–(D.7) согласованно получаем:
>
> ν_prec ≈ 0.186 Δt_prec⁻¹, γ_prec ≈ 1.19·10⁻⁴ Δt_prec⁻¹,        (D.8′)
> ν_breath ≈ 0.244 Δt_breath⁻¹, γ_breath ≈ 2.04·10⁻⁴ Δt_breath⁻¹,
> τ_φ ≈ 1/γ_breath ≈ **4908 Δt_turnover**.
>
> (Альтернативная прочтёнка (D.7) через α₂ даёт γ_breath ≈ 1.90·10⁻⁵ и
> τ_φ ≈ 52755 оборотов; обе прочтёнки указаны для прозрачности.) Оценка (D.8′)
> означает: φ-конфигурация устойчива примерно на **5·10³ оборотов** турбулентного
> вихря — это в ~15 раз больше ранее заявленного значения 322 и на два порядка
> превышает характерные времена перестройки крупных когерентных структур в 2D
> турбулентности (∼10–50 Δt_turnover). Тем самым вывод о долгоживущих
> φ-конфигурациях **усиливается**. Коэффициент модуляционного закона (8) для
> дыхательной моды следует принимать равным α₂ = 0.0119 (D.6b), а не 0.82;
> численная верификация (8) в §5.3 при этом сохраняет силу как проверка
> квадратичной формы закона, но не конкретного коэффициента.

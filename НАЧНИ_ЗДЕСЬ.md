## ЧАСТЬ 1. Подготовка на сайте GitHub (5 минут, можно с телефона в браузере)

### Шаг 1. Войди на GitHub

Открой в браузере https://github.com и войди под логином
**wild8highlander**.

### Шаг 2. Создай ПУСТОЙ репозиторий

1. Нажми **+** (правый верхний угол) → **New repository**.
2. В поле **Repository name** введи точно: `navier-stokes-b`
   (маленькими буквами, через дефис, без пробелов).
3. **НИЧЕГО не отмечай галочками**: ни «Add a README file», ни
   «Add .gitignore», ни «Choose a license» — всё это уже есть в архиве.
4. Нажми зелёную кнопку **Create repository**.
5. Появится страница с подсказками и командами — просто закрой её,
   ничего там вводить не надо.

> ✅ Проверка: открой https://github.com/wild8highlander/navier-stokes-b —
> страница существует и почти пустая («Quick setup»).

### Шаг 3. Создай токен доступа (это «пароль» для публикации)

GitHub не принимает обычный пароль для публикации — нужен токен.

1. Нажми на свою **аватарку** (правый верхний угол) → **Settings**.
2. Прокрути меню слева в самый низ → **Developer settings**.
3. **Personal access tokens** → **Tokens (classic)**.
4. Справа вверху: **Generate new token** → **Generate new token (classic)**.
5. Заполни:
   - **Note**: напиши `termux-push` (это просто подпись);
   - **Expiration**: выбери `90 days`;
   - **Select scopes**: поставь галочку ☑ **repo** (первая строка, целиком).
6. Внизу нажми зелёную кнопку **Generate token**.
7. На экране появится длинная строка вида `ghp_AbC123...` —
   **СРАЗУ скопируй её** в заметки. После ухода со страницы GitHub её
   больше НИКОГДА не покажет. Потеряешь — просто создай новый токен тем
   же способом.

> ✅ Проверка: в заметках телефона лежит строка, начинающаяся с `ghp_`.

## ЧАСТЬ 2. Установка Termux (5 минут)

### Шаг 4. Поставь Termux из F-Droid

1. Скачай F-Droid: https://f-droid.org/F-Droid.apk
   (открой ссылку в браузере телефона → «Скачать» → разреши установку).
2. Открой F-Droid → поиск → введи `Termux` → установи.
3. **Важно:** Termux из Play Market НЕ подходит — он устарел. Только F-Droid!

### Шаг 5. Первые команды в Termux

Открой Termux — чёрный экран со строкой `~ $`. Введи две команды
(после каждой жми Enter; на синих экранах установщика просто жми Enter):

```bash
pkg update -y && pkg upgrade -y
pkg install git unzip -y
```

Это займёт 1–3 минуты. Если спросит «Do you want to continue?» — жми `y`
и Enter (обычно не спросит: мы уже передали `-y`).

## ЧАСТЬ 3. Публикация (5 минут)

### Шаг 6. Дай Termux доступ к файлам телефона

В Termux введи:

```bash
termux-setup-storage
```

Выскочит системное окно с запросом доступа к хранилищу → нажми
**Разрешить** (Allow). Ничего не изменится на экране — это нормально.

### Шаг 7. Распакуй архив

Если архив лежит в папке «Загрузки» (Downloads) телефона:

```bash
cd ~/storage/downloads
ls
```

Команда `ls` покажет файлы — найди свой `navier-stokes-b.zip` (или как ты
его назвал/как его назвал браузер). Теперь распакуй:

```bash
unzip navier-stokes-b.zip -d ~
cd ~/navier-stokes-b
```

> Если имя архива другое — в команде `unzip` напиши своё имя файла.
> Если архив в другом месте: `cd ~/storage/shared` (общая память) или
> `cd ~/storage/downloads` (загрузки) — и повтори.

### Шаг 8. ЗАПУСТИ СКРИПТ ПУБЛИКАЦИИ 🎉

```bash
chmod +x push_wild8highlander.sh
./push_wild8highlander.sh
```

Скрипт всё сделает сам: настроит git, подключит твой репозиторий,
сделает коммит и начнёт отправку (~100 МБ; на мобильном интернете —
несколько минут, не закрывай Termux!).

**В середине процесса** появится вопрос:

```
Username for 'https://github.com': 
```
→ введи `wild8highlander`, Enter.

```
Password for 'https://wild8highlander@github.com':
```
→ **вставь ТОКЕН** (`ghp_...` из Шага 3), Enter.

⚠️ **Три важных момента про вставку токена:**
1. Вставлять нужно **токен** (`ghp_...`), а НЕ пароль от GitHub;
2. В Termux вставка = **долгое нажатие пальцем по экрану → Paste**
   (или потяни шторку уведомлений → коснись уведомления Termux → там
   тоже можно Paste);
3. Во время ввода символы **не отображаются** — так и должно быть,
   просто вставь и жми Enter.

Дождись строки:

```
ГОТОВО: https://github.com/wild8highlander/navier-stokes-b
```

### Шаг 9. Полюбуйся результатом и включи Actions

1. Открой в браузере https://github.com/wild8highlander/navier-stokes-b —
   там теперь весь проект, красивая главная страница с бейджами и описанием.
2. Один раз включи автоматические проверки: на странице репозитория
   **Settings → Actions → General → Allow all actions → Save**.
   Через пару минут бейджи **CI** и **Manifest** на главной станут
   зелёными.

## Если что-то пошло не так (частые ошибки)

| Что видишь | Что случилось | Что делать |
|---|---|---|
| `Authentication failed` | токен неверный/устарел | сделай новый токен (Шаг 3) и запусти скрипт снова |
| «Support for password authentication…» | вставил пароль, а не токен | запусти скрипт снова, вставь `ghp_...` |
| `Repository not found` | репозиторий не создан или имя с опечаткой | проверь Шаг 2 (имя точно `navier-stokes-b`) |
| `unzip: command not found` | нет unzip | `pkg install unzip -y` и повтори |
| `pkg: command not found` | Termux из Play Market | удали и поставь из F-Droid (Шаг 4) |
| Пуш «висит» и не двигается | телефон уснул / сеть слабая | шторка уведомлений → уведомление Termux → **Acquire wakelock**; повтори `./push_wild8highlander.sh` |
| Случайно закрыл Termux на середине | — | просто открой снова и повтори Шаг 8 — скрипт безопасно можно запускать сколько угодно раз |

Более полная таблица решений — в файле `TERMUX_GUIDE.md` внутри папки
репозитория.

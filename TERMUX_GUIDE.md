# 📱 TERMUX_GUIDE — отправка navier-stokes-b на GitHub с Android (Termux)

Пошаговое руководство для аккаунта **wild8highlander**. Однократная
настройка занимает ~10–15 минут; все последующие отправки — одна команда
`./push_wild8highlander.sh`. Инструкция написана для человека, который
Termux видит впервые: каждый шаг описан буквально — где нажать, что
напечатать, что должно появиться на экране.

---

## Шаг 0. Подготовка на GitHub (однократно, с любого устройства)

Эти три действия делаются в браузере — на компьютере или прямо на телефоне
через сайт github.com (не приложение).

### 0.1. Пустой репозиторий

1. Войдите на https://github.com под логином `wild8highlander`.
2. Нажмите **+** в правом верхнем углу → **New repository**.
3. Repository name: `navier-stokes-b` (точно так, строчными, через дефис).
4. Оставьте репозиторий **Public** или выберите **Private** — по желанию.
5. **Не** ставьте галочки «Add a README file», «Add .gitignore»,
   «Choose a license» — всё это уже лежит в папке, а лишние файлы помешают
   первому пушу.
6. Нажмите **Create repository**. Страница с подсказками — закройте, ничего
   там выполнять не нужно.

### 0.2. Personal Access Token (это «пароль» для пуша)

GitHub больше не принимает обычный пароль для git-операций — нужен токен.

1. Правый верхний угол: аватар → **Settings**.
2. В левом меню, в самом низу: **Developer settings**.
3. **Personal access tokens → Tokens (classic)**.
4. **Generate new token → Generate new token (classic)**.
5. Заполните:
   - **Note:** `termux-push` (просто метка);
   - **Expiration:** 90 дней (или No expiration — но безопаснее ограниченный);
   - **Select scopes:** поставьте ☑ **repo** (целиком, со всеми
     подпунктами).
6. Нажмите **Generate token**.
7. **Сразу скопируйте** токен вида `ghp_…` в надёжное место (заметки,
   куда-то ещё). После закрытия страницы GitHub его больше **никогда не
   покажет**. Потеряли — создайте новый, старый отзовите
   (кнопка Delete рядом с ним в списке токенов).

### 0.3. Проверка

Репозиторий `wild8highlander/navier-stokes-b` существует и пуст; токен
`ghp_…` скопирован. Если оба пункта «да» — идите в Шаг 1.

## Шаг 1. Установите Termux

1. Установите **F-Droid**: https://f-droid.org/F-Droid.apk
   (разрешите установку из этого источника в настройках Android).
2. В F-Droid найдите и установите **Termux**.
   ⚠️ Версия из Play Market устарела и не поддерживается — только F-Droid!
3. Откройте Termux. Вы увидите чёрный экран со строкой приглашения вида
   `~ $` — это и есть терминал, сюда печатаем команды.

Первым делом обновите пакеты (потребуется интернет, 1–3 минуты):

```bash
pkg update -y && pkg upgrade -y
pkg install git unzip -y
```

На вопросы установщика (синие экраны) просто жмите Enter — значения по
умолчанию подходят.

## Шаг 2. Перенесите архив на телефон

### Вариант А — архив уже скачан на телефон

1. Скачайте `navier-stokes-b.zip` любым способом (браузером, мессенджером).
2. В Termux дайте доступ к хранилищу:

```bash
termux-setup-storage
```

Появится системный запрос разрешения — нажмите **Разрешить**. В домашней
папке появится `~/storage`.

3. Распакуйте архив туда, где он лежит (обычно «Загрузки»):

```bash
cd ~/storage/downloads        # или ~/storage/shared — куда скачали
ls                            # посмотрите имя файла
unzip navier-stokes-b.zip -d ~
cd ~/navier-stokes-b
```

Если архив называется иначе — подставьте своё имя в unzip.

### Вариант Б — скачать прямо в Termux по прямой ссылке

```bash
pkg install wget -y
wget "<ПРЯМАЯ_ССЫЛКА_НА_НАВИЕР-СТОКС-b.zip>" -O ~/nsb.zip
unzip ~/nsb.zip -d ~
cd ~/navier-stokes-b
```

## Шаг 3. Отправьте репозиторий

Ничего вручную инициализировать не нужно — скрипт сам сделает `git init`,
если папка ещё не репозиторий:

```bash
chmod +x push_wild8highlander.sh
./push_wild8highlander.sh
```

При первом запуске git спросит учётные данные:

```
Username for 'https://github.com': wild8highlander
Password for 'https://wild8highlander@github.com': <вставьте ТОКЕН, Шаг 0.2>
```

⚠️ Ключевые правила вставки:
- вставляйте **токен** (`ghp_…`), а НЕ пароль от GitHub;
- в Termux вставка — **долгое нажатие по экрану → Paste** (или по шапке
  уведомления Termux);
- при вводе символы **не отображаются** — это нормально, просто вставьте
  и нажмите Enter.

Учётные данные запомнятся (`credential.helper store`) — все следующие пуши
проходят без вопросов.

Если скрипт печатает `ОШИБКА push` — не страшно: раздел
[«Частые проблемы»](#частые-проблемы) ниже разбирает каждый случай.

## Шаг 4. Проверьте результат

Откройте в браузере https://github.com/wild8highlander/navier-stokes-b —
файлы на месте, главная страница с бейджами видна. Затем один раз
включите Actions: **Settings → Actions → General → Allow all actions** —
бейджи CI и Manifest станут зелёными после первого прогона.

## Повторные отправки

```bash
cd ~/navier-stokes-b
./push_wild8highlander.sh "что изменилось — одно предложение"
```

Полезный флаг: `./push_wild8highlander.sh --manifest "правка"` — перед
коммитом перегенерирует `MANIFEST.json` (нужно после правки содержимого
файлов).

## Частые проблемы

| Симптом | Причина | Решение |
|---|---|---|
| `Authentication failed` | токен просрочен или скопирован не полностью | создайте новый токен (Шаг 0.2); старый удалите в списке токенов |
| `Support for password authentication was removed` | вставлен пароль вместо токена | повторите пуш, вставьте `ghp_…`-токен |
| `Repository not found` | репозиторий не создан или опечатка в имени | проверьте Шаг 0.1: имя ровно `navier-stokes-b` |
| `remote origin already exists` | не ошибка | скрипт сам обновляет URL origin |
| `error: src refspec main…` | нет ветки main | `git checkout -b main`, затем повторите пуш |
| Push «висит» / обрывается | медленная мобильная сеть | возьмите wakelock (ниже) и повторите; объём ~100 МБ |
| Termux закрывается в фоне | система усыпила процесс | в шторке уведомлений Termux: **Acquire wakelock** перед пушем |
| `pkg: command not found` | установлен Termux не из F-Droid | удалите, поставьте из F-Droid (Шаг 1) |
| `unzip: command not found` | не установлен unzip | `pkg install unzip -y` |
| Слетели учётные данные | переустановка Termux | введите заново при следующем пуше — скрипт всё запомнит |

## Wakelock: чтобы телефон не уснул посреди пуша

1. Опустите шторку уведомлений Android.
2. Найдите уведомление Termux, коснитесь его.
3. Нажмите **Acquire wakelock**.
4. После окончания работы: **Release wakelock**.

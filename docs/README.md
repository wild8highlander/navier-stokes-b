# 📚 Docs — Word Monographs of the Collections

> **Navigation:** **`docs`**

![Format](https://img.shields.io/badge/Format-DOCX-blue?style=flat-square) ![License](https://img.shields.io/badge/License-IPL--RP--1.0-red?style=flat-square)

The Word-manuscript layer of the b-correction program: complete, figure-rich
editions of the monographs — the English (`en/`) and Russian (`ru/`) ones — preserved exactly
as they circulated while the papers in [`papers/`](../papers/README.md) were being prepared.
Each `.docx` contains the full text with embedded illustrations and
editorial formatting, from which the journal PDF version was subsequently assembled.

These editions are needed when you want to annotate the argument, quote with
page anchors, or trace which illustrations accompanied which
manuscript revision. They are documentation artifacts, not build inputs — nothing
in the repository compiles them. The authoritative typeset versions are the PDF
pairs in `papers/`, and the LaTeX sources are in [`src/`](../src/README.md).

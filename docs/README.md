# 📚 Docs — Word-монографии коллекций

> **Навигация:** **`docs`**

![Format](https://img.shields.io/badge/Format-DOCX-blue?style=flat-square) ![License](https://img.shields.io/badge/License-IPL--RP--1.0-red?style=flat-square)

Слой Word-рукописей программы b-коррекции: полные, насыщенные фигурами
редакции монографий — английская (`en/`) и русская (`ru/`) — сохранённые ровно
в том виде, в каком циркулировали при подготовке статей из [`papers/`](../papers/README.md).
Каждый `.docx` содержит полный текст со встроенными иллюстрациями и
редакторским форматированием, из которого впоследствии была собрана журнальная PDF-версия.

Эти редакции нужны, когда требуется аннотировать аргумент, цитировать с
привязкой к страницам или проследить, какие иллюстрации сопровождали какую
редакцию рукописи. Это документационные артефакты, а не входы сборки — ничего
в репозитории их не компилирует. Авторитетные типографские версии — пары PDF
в `papers/`, LaTeX-исходники — в [`src/`](../src/README.md).

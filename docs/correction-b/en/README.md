English-language Word edition of the correction-b monograph with embedded figures. This single `.docx` (~8.6 MB) is the complete English manuscript — the editorial predecessor of the typeset paper in [`papers/correction-b/`](../../../papers/correction-b/README.md). It preserves the manuscript layout: derivation of *b* from the Kirchhoff system, the rotation-angle mechanism, the BKM reduction, and the figure set as originally placed.

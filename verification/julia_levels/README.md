# Julia-верификация, уровни L1–L5

**Полностью независимая реализация** на чистом stdlib Julia:

* L1 — BigFloat (120 бит), формулы против строковых эталонов 50 знаков;
* L2 — алгебра поворота (1000 векторов × 200 осей, собственная матрица Родригеса);
* L3 — вихри Кирхгофа: порядок RK4, изометрия, сохранение площади;
* L4 — 2D NSE: **собственный FFT radix-2 с самотестом против прямого DFT**,
  2/3-правило с 2N-паддингом, тождество ω′ = cos θ_b·ω, энергетика;
* L5 — 3D Тейлор–Грин N=32: BKM-интеграл, непрерывный b-поворот
  (сглаженная ось k ≤ N/6, квадратичный вес), 2N-паддинг.

Ничего не устанавливать: никаких FFTW, JSON и прочих пакетов не требуется.

## Запуск

```bash
julia verify_all.jl                 # всё; L5 ≈ 5–15 мин
NSE3D_SKIP=1 julia verify_all.jl    # без L5 (~минута)
NSE3D_SMALL=1 julia verify_all.jl   # L5 в контрольном режиме
```

Результаты каждого запуска сохраняются в `results/*.json`.

Отличия от Python-версии честно задокументированы: Julia-L5 использует N=32
(собственный FFT требует степень двойки), Python-L5 — N=48; это два независимых
эталона, а не одна задача на двух языках. Сверка констант L1–L4 — `scripts/compare_python_julia.py`.

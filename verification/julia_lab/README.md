# ⚡ NSB Julia Lab

*A self-contained Navier–Stokes laboratory in Julia — zero external packages.*

[RU](DOCS_RU.md) · [EN](#-features) · Version 1.0.0

---



A Julia edition of the `navier-stokes-b` research laboratory (see also
`research_lab/` — the Python/numpy version). Everything is written from scratch
inside one codebase: an in-house radix-2 FFT, a pseudospectral 3D Navier–Stokes
solver (RK4 + Leray projection + 2/3 dealiasing), a 2D barotropic β-plane model,
BKM diagnostics, 600-dpi PNG plotting with an in-house TTF rasterizer
(Cyrillic + math), an in-house vector PDF generator (Type0/Identity-H with
ToUnicode), an interactive bilingual TUI, and TXT/MD/HTML+SVG/JSON/CSV export.

### Requirements

* Julia **1.10+** — the only dependency
* 4+ GB RAM for N≤128; 16+ GB for N≤192

### Run

```bash
julia -t auto julia_lab/navier_stokes_lab.jl            # interactive menu
julia -t auto julia_lab/navier_stokes_lab.jl --quick    # mini-suite + final PDF
julia -t auto julia_lab/navier_stokes_lab.jl --suite hard
julia -t auto julia_lab/navier_stokes_lab.jl --experiment tg --n 64 --t 4
julia -t auto julia_lab/navier_stokes_lab.jl --flow katrina   # or all/list
julia -t auto julia_lab/navier_stokes_lab.jl --roadmap
```

### Features

* Interactive numbered menu, instant **RU ↔ EN** toggle (press **9** anywhere);
* **Quick run** as a separate menu item;
* Tests verify **convergence-to-infinity**: BKM integral, sup|ω|, λ(t) growth scans,
  t* extrapolation with honest caveats; any grid sizes and parameters;
* Each test has **normal and hard modes** (hard = more criteria: RK4 ladder, N→2N
  resolution gap, CFL audit, enstrophy balance, more kicks);
* **Real-flows laboratory**: 20 documented flows — hurricanes Katrina/Haiyan/Patricia,
  Jupiter's Great Red Spot, Saturn's hexagon, polar jet, Kármán street, Gulf Stream,
  Kuroshio, Agulhas, ACC, Draupner rogue wave, Tōhoku tsunami, Qiantang bore,
  Reynolds pipe, Taylor–Couette, Bénard–Rayleigh, Moore tornado, Mount Washington,
  Kelvin–Helmholtz; per-flow: documented data card → derived Re/Ro/β/t_adv/η/N_DNS →
  DNS feasibility → reduced model run or the b-rotation audit on the wave orbital field;
* **Progress bars** with ETA, **scrolling pager**, colored verdicts, terminal-rendered
  vorticity snapshots, sparklines;
* Dedicated **600-dpi plotting system** (own TTF rasterizer, viridis/coolwarm maps);
* Reports in **TXT, MD, HTML+SVG, JSON, CSV** and a final **PDF mini-article**
  generated by an in-house vector PDF engine (Type0/Identity-H + ToUnicode);
* **Roadmap & hardware calculator**: benchmarks the in-house FFT and estimates
  wall time for v0.2–v0.5 (Taylor–Green N=128–256, ABC/Kida–Pelz, Rust/C++ port,
  interval-arithmetic CAP) on *this* machine.

### Scientific honesty

The lab reproduces the Python `research_lab/` conclusions: the full lattice
symmetry is a relabeling (~1e-16 agreement); the pointwise rotation is an isometry
that injects divergence for vortical fields (div(Ru) = cosθ·div u + sinθ·curl u —
verified numerically; for irrotational wave fields it preserves div); the effect
on sup|ω| is within tolerance — **no regularization mechanism found** (an honest
zero result).

# ⚡ NSB Julia Lab (RU)



Julia-версия исследовательской лаборатории репозитория `navier-stokes-b`
(см. также `research_lab/` — Python/numpy-версия). Все компоненты написаны с нуля
и входят в один код: собственный FFT (radix-2), псевдоспектральный 3D-решатель
Навье–Стокса (RK4 + Лере-проекция + 2/3-деалиасинг), 2D баротропная β-плоскость,
BKM-диагностика, PNG-графика 600 dpi со собственным TTF-растеризатором
(кириллица + математика), векторный PDF-генератор (Type0/Identity-H, ToUnicode),
интерактивное двуязычное меню, экспорт TXT/MD/HTML+SVG/JSON/CSV.

### Требования

* Julia **1.10+** — единственная зависимость ([julialang.org/downloads](https://julialang.org/downloads/))
* 4+ ГБ RAM для N≤128; 16+ ГБ для N≤192

### Запуск

```bash
# интерактивное меню (русский по умолчанию)
julia -t auto julia_lab/navier_stokes_lab.jl

# быстрый прогон: мини-сьют + финальный PDF (≈2–5 мин)
julia -t auto julia_lab/navier_stokes_lab.jl --quick

# полная сьют: normal / hard (в hard — больше критериев и выше N)
julia -t auto julia_lab/navier_stokes_lab.jl --suite normal
julia -t auto julia_lab/navier_stokes_lab.jl --suite hard

# отдельные эксперименты с любыми параметрами
julia -t auto julia_lab/navier_stokes_lab.jl --experiment tg --n 64 --nu 0.01 --dt 0.0025 --t 4
julia -t auto julia_lab/navier_stokes_lab.jl --experiment scan --ic abc --n 32

# лаборатория реальных течений (20 документированных объектов)
julia -t auto julia_lab/navier_stokes_lab.jl --flow list
julia -t auto julia_lab/navier_stokes_lab.jl --flow katrina
julia -t auto julia_lab/navier_stokes_lab.jl --flow all --mode hard

# роадмап и бенчмарк этого железа
julia -t auto julia_lab/navier_stokes_lab.jl --roadmap

# язык/язык интерфейса: --lang ru|en (или env NSB_LAB_LANG)
```

`-t auto` включает многопоточный FFT (на 2 ядрах ~×1.8, на 8 ядрах ~×5).

### Научная честность

Лаборатория воспроизводит выводы Python-версии `research_lab/`:

* **полная решётчатая симметрия** u′(x) = R u(R⁻¹x) — релебелинг: диагностики совпадают до ~1e-16;
* **точечный поворот** u′(x) = R u(x) — изометрия (энергия сохранена), но инъецирует
  div (для вихревых полей); тождество div(Ru) = cosθ·div u + sinθ·curl u проверяется
  численно — для безвихревых волновых полей b-поворот сохраняет div;
* **эффект на sup|ω| в пределах допуска (<5%)** — механизма регуляризации не обнаружено
  (честный нулевой результат);
* «сходимость в бесконечность» сканируется через λ(t) = d/dt ln sup|ω|; t* экстраполируется
  только при устойчивом росте λ с R² > 0.9, иначе отчёт честно говорит «сигнала нет».
